# Security Case Studies

This folder contains security investigations based on realistic cybersecurity scenarios commonly encountered by Security Operations Center (SOC) teams.

Each case study follows a structured incident response methodology designed to demonstrate analytical thinking, investigation techniques, evidence correlation, and security decision-making.

---

## Purpose

The objective of these case studies is to showcase practical cybersecurity skills through the investigation of simulated security incidents and suspicious activity.

These scenarios focus on:

- Incident triage
- Alert validation
- Threat identification
- Evidence collection
- Root cause analysis
- MITRE ATT&CK mapping
- Containment recommendations
- Security reporting

## Investigation Framework

Each case study follows the same methodology:

### 1. Incident Overview

Description of the alert or suspicious activity.

### 2. Initial Findings

Review of indicators and available security telemetry.

### 3. Investigation Process

Detailed analysis performed during the investigation.

### 4. Evidence Collected

Relevant logs, events, user activity, IP addresses, devices, and security artifacts.

### 5. MITRE ATT&CK Mapping

Identification of associated tactics and techniques.

### 6. Findings and Analysis

Assessment of the activity and potential risk.

### 7. Response Actions

Recommended containment and remediation actions.

### 8. Lessons Learned

Security improvements and monitoring recommendations.
